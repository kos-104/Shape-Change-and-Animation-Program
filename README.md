## Description

This VBA program lets users select pre-set shapes and color them based on user input. Users can then choose to rotate the shape based on different options.

The program was designed to illustrate Excel's real-time, powerful, and dynamic animation capabilities. It utilizes **constants** for clean, maintainable configuration, and employs a **class module** for encapsulation and event trapping — offering an early demonstration of object-oriented principles within a lightweight, visually engaging tool.




Utilizes extensive VBA code to organize, control, and direct the program.
